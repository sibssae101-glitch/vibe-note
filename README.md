# 바이브 노트 (웹판)

날마다 **한 일 · 쓴 기준 · 결정한 것 · 해야 할 거**를 한 줄씩 적는 노트의 웹 버전입니다.
파일을 내려받거나 설치할 필요 없이 **주소만 열면** 되고, 안드로이드 크롬에서는
**홈 화면에 추가**하면 앱처럼 열립니다.

- 화면: **일정**(월 달력 · 날짜별 기록 · 체크박스 · 한 줄 추가)과 **메모**(날짜별 메모) 두 탭
- 저장: 각자 폰 브라우저의 `localStorage` 에만 남습니다. 서버가 없고, 어디로도 보내지 않습니다.
- 첫 방문에는 무엇을 적는 노트인지 보이도록 **예시 기록**이 채워져 있고, `예시 지우기` 로 한 번에 비울 수 있습니다.
- 외부 CDN·폰트·추적 스크립트를 쓰지 않습니다(단일 HTML + 아이콘 + 서비스 워커).

## 주소

https://sibssae101-glitch.github.io/vibe-note/

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 화면 전체(HTML·CSS·JS 한 장, 외부 요청 없음) |
| `manifest.webmanifest` | 홈 화면에 추가할 때 쓰는 이름·아이콘·색 |
| `sw.js` | 오프라인 캐시(한 번 열면 인터넷 없이도 열림) |
| `icon-*.png` | 홈 화면 아이콘 |

## 고칠 때

1. `index.html` 을 고친다.
2. 오프라인 캐시를 새로 받게 `sw.js` 의 `vibe-note-v1` 숫자를 올린다(`vibe-note-v2` …).
3. `main` 에 올리면 1~2분 뒤 GitHub Pages 에 반영된다. 이미 한 번 열어 본 사람은
   서비스 워커가 이전 화면을 캐시에 들고 있어, 다음에 열 때 새로 받아 간다.

기록은 방문자 브라우저에 있으므로 화면을 고쳐도 지워지지 않습니다.
